# achadinhos-leads-snapshot

Só um número agregado, sem dado pessoal nenhum (nenhum telefone, nome ou
identificador de pessoa real) — contagens de leads do projeto
[Achadinhos Prime](https://achadinhosprime.net.br) (Telegram + WhatsApp).

Escrito automaticamente por `leads_kv_sync.py` (repo privado
`vendas_online`) a cada execução dos scripts de lead — 1 commit só,
sempre sobrescrito (sem histórico acumulando). Lido por uma rotina
agendada que mantém o painel interno de métricas atualizado.
